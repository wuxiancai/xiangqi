# 技术决策

## 已定

- 首版是静态 HTML/CSS/JavaScript ES Modules 单页应用，默认 SVG 棋盘。
- 棋规模块与视图分离；内部着法用结构化对象，棋谱持久化用版本化 `xiangqi-study/v1` JSON，坐标用 ICCS 起止坐标。初始局面支持标准开局或明确 side-to-move 的中国象棋 FEN，以表达残局题局。
- 首版仅接受 UTF-8 JSON 棋谱；XQF、PGN、ICCS 文本留作独立适配器。PGN 不作为中国象棋原生规范。
- 用户数据首版保存在 IndexedDB；存储通过 repository 接口隔离。后端和 PostgreSQL 仅在账号、跨设备同步、备份或协作需要时引入。
- 首版内置棋谱不少于 100 盘，现代棋谱逐条登记来源与许可；未经授权核验的内容不发布。
- 自动播放每步可设 250–5000 ms；关键着法以可验证战术/编辑标注确定，解说 1–50 个中文字符，缺少可靠内容显示“暂无解说”。
- 移动端最低验收视口为 360×640 CSS px，主要触控目标至少 44×44 CSS px。
- AI 适配器首版仅提供 OpenAI-compatible 接口。大语言模型只做分析/候选说明；所有候选须来自或通过本地合法走法校验。AI 棋力未由引擎对局基准证明前，不宣称达到业余高手。

## 变更门槛

- SVG 只有在目标设备 p95 操作响应超过 100 ms 且 Canvas 原型实测达标时才替换。
- 只有出现真实跨设备/账户/服务端备份需求时才引入数据库和 API；领域模型保持不变。
- 只有在第三方兼容需求明确、解析可靠且许可可接受时增加棋谱格式。
- 只有许可审查通过且基准赛达标后，才开放具备棋力等级承诺的 WASM 引擎。
