# 技术决策

## 已定

- 手机端采用跨平台 PWA，不要求 Apple/Google 开发者账号或应用商店。Android 浏览器提供安装提示；iOS 提供 Safari“添加到主屏幕”引导。应用外壳及本地数据支持离线读取，Pikafish 官方版本检查和远端引擎文件下载需要联网。

- 首版是静态 HTML/CSS/JavaScript ES Modules 单页应用，默认 SVG 棋盘。
- 棋规模块与视图分离；内部着法用结构化对象，棋谱持久化用版本化 `xiangqi-study/v1` JSON，坐标用 ICCS 起止坐标。初始局面支持标准开局或明确 side-to-move 的中国象棋 FEN，以表达残局题局。
- 界面将结构化着法显示为中国象棋中文记谱（红方汉字数字、黑方阿拉伯数字）；ICCS 仅用于数据交换与内部坐标，不直接展示为面向用户的着法。
- 棋盘上沿标黑方路数 1–9，下沿标红方路数九–一；翻转棋盘时坐标按屏幕方位同步调整。
- 国内对弈按中国象棋协会《象棋竞赛规则（2020版）》执行；国家体育总局棋牌中心公布的 2026 全国赛事规程仍引用该版。对重复局面，应用识别三次相同循环，并处理单方长将、直接长捉与一将一捉；长将单方立即判负，其他循环提示两回合内变着，持续则按双方循环性质裁定。复杂棋例（长杀、联合捉、假根及第26.9条特殊组合）尚未完整程序化。
- 自然限着按连续 120 个半回合未吃子判和，110 步时提示；任何吃子后计数归零。提和审核及超出每方 10 次将军的计数例外尚未实现。
- JSON 仍为唯一内部/持久化规范。导入适配层支持 JSON、XQF/CBL 主线（含目录和子目录批量导入；CBL 可含多盘）、棋谱文本（中文记谱/ICCS，含常见 PGN 包装）、DOCX、PDF 与常见图片 OCR；提取文本由用户预览修订，转换着法逐手通过规则合法性校验。XQF/CBL 文件在本机解析，变着树暂不导入。旧版二进制 DOC、加密文档及棋盘截图局面识别暂不支持；PGN 不作为中国象棋原生规范。DOCX/PDF/OCR 解析器按需从 CDN 加载，文件不上传。
- 设置/对局保存在 IndexedDB；导入棋谱在自托管模式下由轻量本地 API 持久化至 `data/imported/*.json`，静态托管降级到 IndexedDB。repository 合并两处棋谱并支持覆盖/删除；部署升级保留该目录。该文件夹不纳入 Git。
- 首版内置棋谱不少于 100 盘，现代棋谱逐条登记来源与许可；未经授权核验的内容不发布。
- 自动播放每步可设 250–5000 ms；关键着法以可验证战术/编辑标注确定，解说 1–50 个中文字符，缺少可靠内容显示“暂无解说”。
- 移动端最低验收视口为 360×640 CSS px，主要触控目标至少 44×44 CSS px。
- AI 适配器首版仅提供 OpenAI-compatible 接口。大语言模型只做分析/候选说明；所有候选须来自或通过本地合法走法校验。AI 棋力未由引擎对局基准证明前，不宣称达到业余高手。

## 变更门槛

- SVG 只有在目标设备 p95 操作响应超过 100 ms 且 Canvas 原型实测达标时才替换。
- 只有出现真实跨设备/账户/服务端备份需求时才引入数据库和 API；领域模型保持不变。
- 增加棋谱格式须有明确需求，并逐手规则校验；XQF 暂限定为主线导入。
- 只有许可审查通过且基准赛达标后，才开放具备棋力等级承诺的 WASM 引擎。

## 2026-10-17 Pikafish 与 AI 研究工作台

- 对弈视图以棋盘为主，右侧提供局面设置、Pikafish 候选着法和本局棋谱；窄屏改为棋盘优先纵向布局。参考 xiangqiai.com 的棋盘研究、候选着法、AI 对弈与复盘用途。
- 增加可选 Pikafish WebAssembly UCI 适配器。引擎只在用户点击“加载引擎”后启动；未构建资源时保留现有本地搜索。Pikafish 走子仍须通过应用当前合法着法集合校验。
- 坐标边界必须显式转换：应用内部 rank 0 在黑方底线、Pikafish UCI rank 0 在红方底线；FEN 从黑方底线（应用 rank 0）排到红方底线（rank 9），并保留应用棋子大小写（红方大写、黑方小写）；导入 bestmove/PV 时将 rank 转为 `9-rank`。引擎着法在展示或执行前仍经本地合法着法校验。
- 不在 Git 中携带编译产物或 NNUE 文件；源码构建固定版本、显式提供 GPL 文本与 NNUE 独立许可。公开或商业分发前需履行 GPL 对应源码义务，并单独确认 NNUE 网络用途许可。
- 多线程 WASM 要求 COOP/COEP；项目自托管服务发送隔离响应头。静态托管需配置相同响应头，否则 Pikafish 线程构建不可用。
- Pikafish 可用性不代表本应用已经通过棋力基准认证。对局等级承诺和基准赛仍按现有 AI 验收门槛执行。
